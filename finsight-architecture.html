LLM / RAG Pipeline
How a user question becomes an AI answer — step by step
📤 Ingestion Pipeline (runs after CSV upload)
1
Parse CSV
Read bank statement. Clean columns. Normalize dates and amounts. Handle missing values.
pandas
PyMuPDF
↓ list of transaction dicts
2
Categorize Transactions
Match description keywords → category labels. Store in DB with category_id.
keyword rules
scikit-learn
↓ categorized transactions → saved to SQLite
3
Generate Embeddings
Convert each transaction to a semantic vector. Text = "date + description + amount + category".
sentence-transformers
all-MiniLM-L6-v2
↓ 384-dim vectors
4
Store in ChromaDB
Upsert vectors with metadata (user_id, date, category, amount). Scoped per user.
ChromaDB
local disk
💬 Query Pipeline (runs on /chat/ask)
1
Receive Question
User sends: "Where am I overspending this month?" — validate JWT, extract user_id.
FastAPI
Pydantic
↓ validated ChatRequest
2
Embed the Question
Convert question to same vector space as transaction embeddings using same model.
sentence-transformers
↓ query vector
3
Semantic Search
ChromaDB cosine similarity search. Retrieve top-5 most relevant transactions. Filter by user_id.
ChromaDB
top_k=5
↓ relevant transaction context
4
Build Prompt
Inject retrieved transactions into prompt template with user's question. Add financial advisor system prompt.
prompt engineering
↓ rich contextual prompt
5
Ollama → Mistral 7B
POST to localhost:11434/api/generate. Stream response tokens back to user. Fully local, zero cost.
Ollama
Mistral 7B
streaming
↓ streamed AI response
6
Save + Return
Persist Q&A + sources to chat_history table. Return answer with transaction references to frontend.
SQLite
JSON response
